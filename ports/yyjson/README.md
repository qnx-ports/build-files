# yyjson for QNX 8.0

Generated by [qnx-porter](https://github.com/thegoodengineers/qnx-porter) from its automatic port of
yyjson `0.10.0` (https://github.com/ibireme/yyjson.git). On a QNX 8.0 x86_64 target (QEMU) 12/12 of its own tests passed. Full report:
`ports-2024/yyjson/REPORT.md` in qnx-porter.

## Build
```bash
source ~/qnx800/qnxsdp-env.sh
git clone --depth 1 --recurse-submodules --shallow-submodules --branch 0.10.0 https://github.com/ibireme/yyjson.git yyjson
QNX_PROJECT_ROOT="$(pwd)/yyjson" make -C build-files/ports/yyjson install JLEVEL=4
```

## QNX changes, each with its reason
| rule | reason |
|---|---|
| link-libm | `__isinf` is in QNX's libm, not in libc: QNX's <math.h> implements isinf/isfinite/isnan as calls to __isinf etc. in libm, where glibc needs no library. Link with -lm. |
